# Fullstack Assignment

## Environment & Versions:
- **PHP**: 8.3.36
- **Laravel**: 13 (with Sanctum & /api/health endpoint)
- **Node.js**: LTS
- **React**: 19.3.1 (Vite + TypeScript)
- **Tailwind CSS**: v4
- **UI Library**: shadcn/ui (Button Component)
- **Database**: MySQL / MariaDB (fullstack_db via XAMPP)

## Setup & Run Commands:

### Backend:
cd backend
composer install
php artisan migrate
php artisan serve

### Frontend:
cd frontend
npm install
npm run dev
